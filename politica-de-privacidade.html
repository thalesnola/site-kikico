Política de privacidade

Última atualização: 26 de novembro de 2026.

O Mini Mundo do Kikico é um projeto familiar de desenhos calmos para crianças de 1 a 4 anos, feito para os pais e cuidadores. Esta página explica quais dados são tratados, e por quê.

1. Quem cuida do projeto

O projeto é mantido pela família responsável pelo canal e pelo site. Para qualquer dúvida sobre privacidade, escreva para contato@kikico.com.br.

2. O site

O site kikico.com.br não usa cookies, não usa rastreadores, não tem formulários de cadastro e não coleta dados pessoais de quem navega. Ele é apenas uma página de apresentação com links para os vídeos no YouTube.

3. Os vídeos no YouTube

Os vídeos são publicados no YouTube. Ao assistir, o YouTube aplica a própria política de privacidade do Google, sobre a qual o projeto não tem controle. Recomendamos que pais e responsáveis usem o modo de conta supervisionada e o controle de tempo de tela disponíveis no próprio YouTube e no dispositivo.

4. Acesso à API do YouTube

Para publicar os vídeos e organizar as playlists do canal, uma ferramenta interna do projeto usa a API do YouTube, com autorização explícita da conta Google do próprio canal. Esse acesso serve somente para:

  • enviar vídeos ao canal do projeto;
  • criar e atualizar playlists desse mesmo canal.

Os dados obtidos por meio dessa autorização:

  • não são vendidos, alugados nem compartilhados com terceiros;
  • não são usados para publicidade nem para perfilar pessoas;
  • não são usados para treinar modelos de inteligência artificial;
  • ficam apenas no computador do responsável pelo projeto, e o acesso pode ser revogado a qualquer momento.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

5. Crianças

O conteúdo é destinado a crianças pequenas, e o canal está marcado como conteúdo feito para crianças. O projeto não coleta dados de crianças. Os comentários dos vídeos ficam desativados.

6. Seus direitos

Você pode pedir a qualquer momento a revisão, a correção ou a exclusão de qualquer dado relacionado a você, escrevendo para contato@kikico.com.br. Para revogar o acesso concedido ao projeto, use a página myaccount.google.com/permissions.

7. Mudanças nesta política

Se esta política mudar, a data no topo da página será atualizada. Quando a mudança for relevante, o aviso também aparecerá no site.
